# CHIP-8 Virtual Machine & Bytecode Emulator in Pure COBOL

An authentic, fully compliant CHIP-8 bytecode emulator written entirely in COBOL-85 / COBOL 2002 (compatible with GnuCOBOL 3.2+).

## Technical Achievements
* **Full Instruction Set**: All 35 classic COSMAC VIP / Telmac CHIP-8 instructions implemented using hierarchical `EVALUATE TRUE` decoders.
* **Predictable Memory Layout**: Emulates 4096-byte memory addressing using a continuous 4KB table, 16 8-bit registers (V0-VF), 16-level call stack, and timers.
* **Monochrome 64x32 Video Display**: Renders the monochrome display matrix in the terminal using ASCII/Unicode block buffering, with XOR blitting and collision detection.

## Building and Running
```cmd
build.bat
run.bat
```
